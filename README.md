NeuroMorph
This repository is a side project of Giulio Matteucci focused on using autoencoders to explore and understand multimodal associations with a simple unsupervised machine learning model.
This repository contains code to train a simple convolutional autoencoder on the MNIST dataset and explore is internal reapresentations, the aim is to and evaluate the capacity of the model to encode arbitrary 
associations between the main input modality (images) and contextual information from other "modalities" and provide a proof of principle / toy model of future behavioral experiments.
